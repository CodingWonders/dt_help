# Supprimer des packages

<p align="center">
    <img src="/res/img_tasks/packages/remove_package.png" />
</p>

Avec DISMTools, vous pouvez supprimer des packages d'une image ou d'une installation Windows. Cette action est disponible dans Commands > OS Packages > Remove package... ou via le bouton « Remove package... ».

## Compatibilité par plateforme

Cette action est compatible avec les plateformes suivantes :

| Plateforme | Pris en charge ? |
|:--:|:--:|
| Windows 7/Server 2008 R2 | ✔ |
| Windows 8/Server 2012 | ✔ |
| Windows 8.1/Server 2012 R2 | ✔ |
| Windows 10/Server 2016/2019/2022 | ✔ |
| Windows 11/Server 2025 | ✔ |

<i>Cette action est prise en charge depuis DISMTools 0.1.1 et versions ultérieures</i>

## Utilisation

Vous pouvez spécifier les noms des packages installés à supprimer, ou indiquer une source de packages et sélectionner les fichiers à retirer de l'image ou de l'installation.

**REMARQUE :** si vous choisissez la seconde option, il est possible de sélectionner des packages qui ne sont pas installés dans l'image ou l'installation ; DISMTools les ignorera.
