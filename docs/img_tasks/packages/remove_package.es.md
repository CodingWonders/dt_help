# Eliminar paquetes

<p align="center">
	<img src="/res/img_tasks/packages/remove_package.png" />
</p>

Con DISMTools puedes eliminar paquetes de una imagen o instalación de Windows. Esta acción está disponible en Comandos > Paquetes del sistema operativo > Eliminar paquete... o mediante el botón "Eliminar paquete...".

## Compatibilidad por sistema operativo

Esta acción es compatible con las siguientes plataformas:

| Plataforma | ¿Soportado? |
|:--:|:--:|
| Windows 7/Server 2008 R2 | ✔ |
| Windows 8/Server 2012 | ✔ |
| Windows 8.1/Server 2012 R2 | ✔ |
| Windows 10/Server 2016/2019/2022 | ✔ |
| Windows 11/Server 2025 | ✔ |

<i>Esta acción es compatible con DISMTools 0.1.1 y posteriores</i>

## Uso

Puedes especificar los nombres de los paquetes instalados que quieras eliminar, o indicar una fuente de paquetes y seleccionar los archivos que deseas quitar de la imagen o instalación.

**NOTA:** si eliges la segunda opción, es posible que selecciones paquetes que no estén instalados en la imagen o instalación; DISMTools los omitirá.
