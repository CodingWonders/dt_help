# Aplicar archivos de respuesta desatendida

<p align="center">
    <img src="/res/img_tasks/unattend/unatt_apply/apply_task.png" />
</p>

Con la tarea de aplicación puedes aplicar fácilmente tus archivos de respuesta desatendida a las imágenes de Windows.

*Esta tarea está disponible en DISMTools 0.5.1 y posteriores.*

## Uso

1. Especifica el archivo de respuesta desatendida a aplicar
2. Haz clic en Aceptar

## Aplicar archivos de respuesta usando las herramientas de creación de ISO

También puedes copiar tu archivo de respuesta a una ISO de prueba mediante el creador de ISO. Marca la opción "Unattended answer file" y especifica el archivo:

<p align="center">
    <img src="/res/img_tasks/unattend/unatt_apply/apply_isocreate.png" />
</p>

Tras instalar el sistema operativo y realizar pruebas de operabilidad, el instalador aplicará el archivo de respuesta. Asegúrate de que el medio con el archivo permanezca disponible o la aplicación podría no completarse correctamente.
