# Gestionnaire de fichiers de réponse non interactive

<p align="center">
    <img src="/res/img_tasks/unattend/unatt_man.png" />
</p>

Le gestionnaire de fichiers de réponse non interactive vous permet d'administrer les fichiers de réponse associés à votre projet. Vous pouvez accéder à cet outil de deux manières :

- Tools > Unattended answer file manager
- Clic droit sur "Unattended answer files" dans l'arborescence du projet puis Manage

*Cet outil est disponible dans DISMTools 0.5.1 et versions ultérieures.*

## Utilisation

Sélectionnez un fichier de réponse non interactive et choisissez l'action à effectuer à l'aide des boutons situés en bas de la fenêtre.
