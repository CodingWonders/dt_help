# Appliquer des fichiers de réponse non interactive

<p align="center">
    <img src="/res/img_tasks/unattend/unatt_apply/apply_task.png" />
</p>

La tâche d'application permet d'appliquer facilement vos fichiers de réponse non interactive aux images Windows.

*Cette tâche est disponible dans DISMTools 0.5.1 et versions ultérieures.*

## Utilisation

1. Indiquez le fichier de réponse à appliquer
2. Cliquez sur OK

## Appliquer via l'outil de création d'ISO

Vous pouvez également copier votre fichier de réponse dans une ISO de test avec l'outil de création d'ISO : cochez l'option "Unattended answer file" et sélectionnez le fichier :

<p align="center">
    <img src="/res/img_tasks/unattend/unatt_apply/apply_isocreate.png" />
</p>

Après installation et tests, l'installateur appliquera le fichier de réponse. Assurez‑vous que le média contenant le fichier reste accessible, sinon l'application peut échouer.
