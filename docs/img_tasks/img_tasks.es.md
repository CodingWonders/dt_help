# Tareas de imagen

Con DISMTools puedes realizar una variedad de tareas, organizadas según la acción que se aplica a una imagen.

## ¿Dónde encuentro las tareas?

Todas las tareas están disponibles desde el menú "Comandos".

<p align="center">
	<img src="/res/img_tasks/cmd_menu.png"/>
</p>

También tienes acceso a las tareas más importantes en el centro de la pantalla.

<p align="center">
	<img src="/res/img_tasks/quick_actions.png"/>
</p>

Ten en cuenta que estas opciones se habilitan cuando creas un proyecto y montas una imagen. Para realizar esos pasos, consulta la guía [Getting started](../getting_started/start.md).

## Tareas disponibles

- Gestión de imágenes

	- Añadir cambios en un nuevo índice de la imagen de Windows
	- Aplicar imágenes de Windows
	- Capturar imágenes de Windows
	- Limpiar puntos de montaje
	- Exportar imágenes de Windows
	- Obtener información de archivos de imagen
	- Realizar limpieza de imagen
    
- Gestión de paquetes

	- Añadir paquetes
	- Eliminar paquetes
	- Obtener información de paquetes

- Gestión de características

	- Habilitar características
	- Deshabilitar características
	- Obtener información de características

- Gestión de paquetes AppX

	- Añadir paquetes AppX
	- Quitar paquetes AppX
	- Obtener información de paquetes AppX instalados
    
- Gestión de capacidades

	- Añadir capacidades
	- Eliminar capacidades
	- Obtener información de capacidades

- Gestión de controladores

	- Añadir controladores
	- Eliminar controladores
	- Exportar controladores a una carpeta
	- Importar controladores desde otra imagen o instalación
	- Obtener información de controladores
