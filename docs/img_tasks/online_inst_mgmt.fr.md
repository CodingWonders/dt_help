# Mode de gestion d'installation en ligne

DISMTools 0.3 et versions ultérieures permettent de gérer l'installation active (appelée « installation en ligne ») en utilisant la même interface que pour les projets et images Windows.

## Accès à ce mode

Vous pouvez accéder à ce mode de deux manières : en cliquant sur « Gérer l'installation en ligne » depuis l'écran principal ou via le menu Fichier.

## Différences par rapport à la gestion de projets

Il existe quelques différences entre la gestion d'une installation en ligne et un projet standard, énumérées ci‑dessous :

- Vous ne pouvez pas enregistrer en mode gestion d'installation en ligne, car toutes les opérations de validation sont désactivées
- Vous ne pourrez effectuer que les actions prises en charge par votre système d'exploitation
- Toutes les options liées à Windows Update sont désactivées si vous gérez l'installation active en mode sans échec (sans capacités réseau)

## Risques liés à la gestion d'une installation en ligne

**REMARQUE :** lisez cette section *seulement* si l'avertissement précédent n'était pas clair.

Avant de gérer l'installation active, considérez les risques suivants :

- Nous recommandons **de sauvegarder le système** au cas où quelque chose tournerait mal pendant le processus
- **N'agissez pas de manière imprudente**. Il s'agit de *votre* système, avec vos fichiers et configurations ; une opération incorrecte pourrait l'endommager, voire le rendre non amorçable
