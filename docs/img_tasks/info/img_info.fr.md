# Informations sur l'image

<p align="center">
    <img src="/res/img_tasks/info/img_info.png" />
</p>

Avec DISMTools, vous pouvez obtenir des informations sur l'image actuellement montée ou sur n'importe quel fichier d'image Windows, afin de consulter les détails d'un index.

_Cette action est disponible dans DISMTools 0.3.1 et versions ultérieures._

## Utilisation

1. Si vous avez chargé un projet contenant une image montée, l'option "Image actuellement montée" est cochée par défaut. Cette option se désélectionne si vous avez chargé un projet sans image montée ou si vous gérez une installation en ligne. Vous pouvez choisir n'importe quel fichier d'image en sélectionnant "Autre image" et en spécifiant le fichier.
2. La vue liste sera remplie avec des informations de base sur les index : numéro d'index et nom de l'image. Sélectionnez un index pour voir les informations détaillées.

## Enregistrer ces informations

Vous pouvez également sauvegarder ces informations en cliquant sur le bouton Save en bas à droite et en indiquant le chemin de destination.
