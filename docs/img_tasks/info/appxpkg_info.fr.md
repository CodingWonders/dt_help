# Informations sur les paquets AppX

<p align="center">
    <img src="/res/img_tasks/info/appxpkg_info.png" />
</p>

Avec DISMTools, vous pouvez obtenir des informations sur les paquets AppX installés dans des images et installations Windows.

*Cette action est disponible dans DISMTools 0.3.1 et versions ultérieures.*

**REMARQUE :** cette action n'est pas prise en charge sur des images ou installations antérieures à Windows 8 / Server 2012.

## Utilisation

- À l'ouverture du dialogue, une liste de tous les paquets AppX s'affiche.
- Pour voir les informations d'un paquet AppX, **sélectionnez‑le dans la liste** ; ses détails apparaîtront à droite.

Le nombre de paquets AppX affichés dépend de la configuration des processus d'analyse en arrière‑plan.

## Détection de l'asset du logo

DISMTools tente d'identifier l'asset principal du logo pour chaque paquet AppX ; la détection peut parfois être erronée.

Si un asset incorrect est affiché, signalez un problème ici : https://github.com/CodingWonders/DISMTools/issues/new?assignees=CodingWonders&labels=bug&projects=&template=store-logo-asset-preview-issue.md&title=
