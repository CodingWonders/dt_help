# Tâches d'image

Avec DISMTools, vous pouvez effectuer une variété de tâches, organisées selon l'action appliquée à une image.

## Où trouver les tâches ?

Toutes les tâches sont accessibles depuis le menu "Commandes".

<p align="center">
    <img src="/res/img_tasks/cmd_menu.png"/>
</p>

Les actions les plus courantes sont aussi disponibles depuis le centre de l'écran.

<p align="center">
    <img src="/res/img_tasks/quick_actions.png"/>
</p>

Ces options sont activées après la création d'un projet et le montage d'une image. Voir la section "Getting started" pour les étapes initiales.

## Tâches disponibles

- Gestion d'images

    - Ajouter des changements dans un nouvel index d'une image Windows
    - Appliquer des images Windows
    - Capturer des images Windows
    - Nettoyer les points de montage
    - Exporter des images Windows
    - Lister les fichiers et dossiers d'une image
    - Effectuer un nettoyage d'image
    
- Gestion de paquets

    - Ajouter des paquets
    - Supprimer des paquets
    - Obtenir des informations sur des paquets

- Gestion des fonctionnalités

    - Activer des fonctionnalités
    - Désactiver des fonctionnalités
    - Obtenir des informations sur des fonctionnalités

- Gestion des paquets AppX

    - Ajouter des paquets AppX
    - Retirer des paquets AppX
    - Obtenir des informations sur les paquets AppX installés
    
- Gestion des capacités

    - Ajouter des capacités
    - Supprimer des capacités
    - Obtenir des informations sur des capacités

- Gestion des pilotes

    - Ajouter des pilotes
    - Supprimer des pilotes
    - Exporter des pilotes vers un dossier
    - Importer des pilotes depuis une autre image ou installation
    - Obtenir des informations sur des pilotes
