# Fusionador de archivos SWM

<p align="center">
	<img src="/res/img_tasks/tools/swm2wim/swm2wim.png" />
</p>

Con DISMTools puedes fusionar archivos SWM (WIM dividido) en un único archivo WIM.

Esta tarea inicia una operación de exportación de imagen con los ajustes necesarios para fusionar las imágenes divididas.

## Uso

1. Especifica el archivo SWM fuente a fusionar. Si hay varios archivos SWM, **elige el primero**
2. Selecciona el índice que quieres añadir a la imagen destino. Encontrarás un resumen de los índices de la imagen
3. Especifica la ubicación de la imagen destino
