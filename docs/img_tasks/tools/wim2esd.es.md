Con DISMTools puedes convertir imágenes entre WIM y ESD (y viceversa).

Esta tarea inicia una operación de exportación de imagen con los ajustes necesarios para realizar la conversión.

## Uso

1. Especifica el archivo de imagen fuente a convertir, que puede ser un archivo WIM o ESD. Si tienes archivos SWM, deberás combinarlos primero. Al seleccionar una imagen fuente, el formato de destino se detecta automáticamente.
2. Selecciona el índice que quieres añadir a la imagen destino. Verás un resumen de los índices de la imagen.
3. Especifica la ubicación del archivo de imagen destino.

### Después de la conversión

Al finalizar el proceso de conversión, tendrás la opción de abrir el directorio donde se guardó el archivo de imagen destino.
