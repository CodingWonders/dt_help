
# Conversion d'images

</p>

Avec DISMTools, vous pouvez convertir des images entre les formats WIM et ESD (et vice‑versa).

Cette tâche lance une opération d'export d'image avec tous les paramètres nécessaires à la conversion.

## Utilisation

1. Spécifiez le fichier image source à convertir, qui peut être un fichier WIM ou ESD. Si vous disposez de fichiers SWM, vous devrez les fusionner. Notez que lorsque vous sélectionnez un fichier source, le format cible est détecté automatiquement.
2. Sélectionnez l'index à ajouter à l'image cible. Vous trouverez un aperçu des index d'une image.
3. Indiquez l'emplacement du fichier image cible.

### Après la conversion

Une fois la conversion terminée, vous aurez la possibilité d'ouvrir le répertoire où vous avez enregistré le fichier image cible.
