
# Fusion de fichiers SWM

<p align="center">
    <img src="/res/img_tasks/tools/swm2wim/swm2wim.png" />
</p>

Avec DISMTools, vous pouvez fusionner des fichiers SWM (WIM fractionné) en un fichier WIM.

Cette tâche lance une opération d'export d'image avec tous les paramètres nécessaires pour fusionner les images fractionnées.

## Utilisation

1. Spécifiez le fichier SWM source à fusionner. S'il existe plusieurs fichiers SWM, **choisissez le premier**
2. Sélectionnez l'index à ajouter à l'image cible. Vous trouverez un aperçu des index d'une image
3. Indiquez l'emplacement du fichier image cible
