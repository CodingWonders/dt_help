# Configurer les pilotes de clavier superposés

<p align="center">
    <img src="/res/img_tasks/langs/set_layereddriver.png" />
</p>

Avec DISMTools, vous pouvez configurer des pilotes de clavier superposés (layered drivers) pour les utilisateurs disposant de claviers japonais ou coréens.

*Cet outil est disponible dans DISMTools 0.5.1 et versions ultérieures.*

## Utilisation

Configurez le pilote superposé en sélectionnant l'un des types suivants, puis cliquez sur OK :

- PC/AT Enhanced Keyboard (101 touches)
- Korean PC/AT 101-Key Compatible Keyboard - Microsoft Natural Keyboard (Type 1/2/3)
- Clavier coréen (103/106 touches)
- Clavier japonais (106/109 touches)
