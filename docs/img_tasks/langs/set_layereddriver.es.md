# Configurar controladores de teclado por capas

<p align="center">
    <img src="/res/img_tasks/langs/set_layereddriver.png" />
</p>

Con DISMTools puedes configurar controladores de teclado por capas para usuarios con teclados japoneses y coreanos.

*Esta acción está disponible en DISMTools 0.5.1 y posteriores.*

## Uso

Configura los controladores por capas seleccionando uno de los siguientes tipos y pulsa OK:

- PC/AT Enhanced Keyboard (101 teclas)
- Korean PC/AT 101-Key Compatible Keyboard - Microsoft Natural Keyboard (Tipo 1/2/3)
- Teclado coreano (103/106 teclas)
- Teclado japonés (106/109 teclas)
