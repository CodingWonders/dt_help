# Explorador de imágenes de Windows

<p align="center">
	<img src="/res/img_tasks/mgmt/WIM_Explorer.png" />
</p>

Si deseas obtener información sobre los archivos y carpetas de una imagen de Windows, puedes usar el **Windows Image Explorer** para esa tarea.

<i>Esta acción está disponible en DISMTools 0.5 y posteriores.</i>

Puedes encontrarlo como parte de DISMTools o usarlo por separado. Consulta el [repositorio de Windows Image Explorer](https://github.com/CodingWonders/WIM-Explorer) para descargarlo.

## Uso

1. Ve a Comandos > Image management > List files and directories in image...
2. Navega

Para más información sobre su uso, consulta el repositorio mencionado.
