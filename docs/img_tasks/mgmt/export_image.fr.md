
# Exporter une image Windows vers un nouveau fichier d'image

<p align="center">
    <img src="/res/img_tasks/mgmt/export_image.png" />
</p>

Si vous souhaitez séparer le travail effectué sur une image Windows du reste des images du fichier, vous pouvez l'exporter facilement vers un nouveau fichier d'image via ce dialogue.

<i>Cette action est disponible dans DISMTools 0.5 et versions ultérieures.</i>

## Utilisation

1. Spécifiez le fichier d'image source à partir duquel exporter l'image Windows modifiée
2. Spécifiez un emplacement pour l'image exportée
3. Choisissez l'index à exporter en utilisant le sélecteur d'index

## Options

Les options applicables à l'exportation suivent les directives en ligne de commande ; consultez-les [ici](https://learn.microsoft.com/fr-fr/windows-hardware/manufacture/desktop/dism-image-management-command-line-options-s14?view=windows-11#export-image).

## Remarques

- Vous pouvez spécifier un nom personnalisé pour le nouveau fichier d'image. Si vous ne le faites pas, le programme utilisera celui du fichier d'image source
