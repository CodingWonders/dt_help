# Exportar una imagen de Windows a un nuevo archivo de imagen

<p align="center">
	<img src="/res/img_tasks/mgmt/export_image.png" />
</p>

Si deseas separar el trabajo realizado en una imagen de Windows del resto de imágenes en el archivo, puedes exportarla fácilmente a un nuevo archivo de imagen con este diálogo.

<i>Esta acción está disponible en DISMTools 0.5 y posteriores.</i>

## Uso

1. Especifica el archivo de imagen fuente desde el que exportar la imagen de Windows modificada
2. Especifica una ubicación para la imagen exportada
3. Elige el índice a exportar usando el selector de índices

## Opciones

Las opciones aplicables al exportar la imagen siguen las guías de línea de comandos; consúltalas [aquí](https://learn.microsoft.com/es-es/windows-hardware/manufacture/desktop/dism-image-management-command-line-options-s14?view=windows-11#export-image).

## Observaciones

- Puedes especificar un nombre personalizado para el nuevo archivo de imagen. Si no lo indicas, el programa usará el establecido por el archivo de imagen fuente
