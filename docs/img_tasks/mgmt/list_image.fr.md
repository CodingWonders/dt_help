
# Explorateur d'images Windows

<p align="center">
    <img src="/res/img_tasks/mgmt/WIM_Explorer.png" />
</p>

Si vous souhaitez obtenir des informations sur les fichiers et dossiers d'une image Windows, vous pouvez utiliser le **Windows Image Explorer** pour cette tâche.

<i>Cette action est disponible dans DISMTools 0.5 et versions ultérieures.</i>

Vous pouvez l'utiliser depuis DISMTools ou en tant qu'outil autonome. Consultez le [dépôt Windows Image Explorer](https://github.com/CodingWonders/WIM-Explorer) pour le télécharger.

## Utilisation

1. Allez dans Commandes > Gestion d'images > Lister les fichiers et répertoires dans l'image...
2. Naviguez

Pour plus d'informations sur son utilisation, consultez le dépôt mentionné.
