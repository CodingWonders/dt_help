# Recargar la sesión de mantenimiento de una imagen

<p align="center">
	<img src="/res/img_tasks/mgmt/remount_image.png" />
</p>

Si la sesión de mantenimiento de una imagen requiere recarga, puedes restaurarla fácilmente. Es una acción rápida que no requiere intervención del usuario.

## Uso

Puedes recargar la sesión de mantenimiento de una imagen de tres maneras:

- En el [gestor de imágenes montadas](../tools/mimgmgr.md), selecciona la imagen cuya sesión quieres recargar y haz clic en "Recargar sesión de servicio"
- Si tienes un proyecto con una imagen montada que requiere recarga de sesión, haz clic en "Recargar sesión de servicio" o recarga el proyecto
- En la versión CLI del gestor de imágenes montadas, marca la imagen que quieras y pulsa R

<p align="center">
	<img src="/res/img_tasks/mgmt/mimgmgr_reload.png" />
</p>

Durante el arranque, el programa intentará recargar la sesión de mantenimiento de todas las imágenes para que puedas empezar a trabajar rápidamente.
