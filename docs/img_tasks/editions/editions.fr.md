# Opérations liées aux éditions d'image

Lors d'opérations sur les éditions d'image, vous pouvez mettre à niveau une image Windows vers une édition supérieure et définir la clé de produit. Vous pouvez également obtenir l'édition actuelle et les éditions vers lesquelles la mise à niveau est possible.

Ces tâches sont disponibles dans Commands > Windows Editions.

## Tâches disponibles

- [Mettre à niveau une image vers une édition supérieure](./set_edition.md)
- [Modifier la clé de produit](./set_productkey.md)
